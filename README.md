# 教育与心智 · 知识图谱

面向**老师**与**家长**的教育、心理与儿童发展知识库：先给可执行的做法，再给背后的机制与证据。

**在线访问**：https://neo-icc.github.io/education-mind-atlas/

---

## 这是什么

一个纯静态的知识图谱站点。它把教育、心理与儿童发展领域的核心理论，整理成六层可检索的结构，并把研究结论转译成老师与家长能直接使用的动作、话术与边界提示。

它不是论文库，也不是科普号：

- 每个条目都区分**学界共识**与**学术分歧**，分歧必须双方并举，不把一方写成结论。
- 每条建议都标注**证据强度**，并写明**何时该找专业帮助**。
- 所有统计从同一份数据实时计算，站内提供数据自检页，不接受「概览与列表数字不一致」。

## 本地运行

无需构建、无需安装依赖。任意静态服务器即可：

```bash
python -m http.server 8899
# 或
npx serve .
```

然后访问 http://localhost:8899/。

> 直接双击 `index.html` 也能打开，但部分浏览器的 `file://` 策略会限制脚本，建议用本地服务器。

### 字体与外部依赖

- **西文与标题字体**：Fraunces / Spline Sans / Spline Sans Mono 已本地化到 `js/vendor/fonts/`，只保留 latin 子集，随页面一起加载。
- **中文字体**：默认使用系统字体（思源 / 宋体 / PingFang / 微软雅黑），同时以非阻塞方式尝试加载 Noto Serif SC 与 Noto Sans SC。加不上只会导致字形差异，不影响布局与功能。
- **D3**：本地化到 `js/vendor/`，CDN 仅作为兜底。

除中文字体这一项渐进增强外，页面不依赖任何外部资源。

## 数据模型

**条目花名册**是紧凑数组，便于快速增删：

```js
["E001", "柏拉图 · 理想国教育思想", "Plato · Education in the Republic",
 "foundation", "edu-philosophy", "plato", -380, "theory", "一句话概括"]
// id, 名称, 英文, 领域, 分支, 人物, 起始年, 类型, 一句话
```

**条目详解**按 id 归并：

```js
ATLAS.details = {
  E001: {
    definition, claims[], agreements[],
    disagreements: [{ topic, sides: [{who, view}, {who, view}], stake }],
    evidence: [{ text }], applications[], terms[{ t, en, d }]
  }
}
```

**DOI 统一由独立映射表补齐**（详解里不写死 DOI，便于整体重新核验）：

```js
ATLAS.dois = { E048: [null, "10.1037/h0069608", "10.1037/h0025984"] }
// 数组下标与同一条目的 evidence 数组严格对齐；null 表示未核验到，不猜测
```

生成方式（可复现）：用 Crossref REST API 按证据文本检索，要求标题包含或 Dice 相似度 ≥ 0.8、年份相差 ≤ 2 年，限速 2 并发并做退避重试；未匹配的一律留空。这样 DOI 与人工撰写的证据文本互不污染，重新核验时只需替换这一个文件。

**关联**是六元组：

```js
["E001", "E031", "derivative", "机制级说明", "established", -400]
// a, b, type(agreement|disagreement|derivative), 说明, 证据强度, since
```

**情境**面向非专业读者：

```js
{ id, age, audience, title, signal, read, links[], do[], dont[], say[], escalate, evidence }
```

## 内容原则与已知边界

1. **不是系统综述**：条目是综述性整理，用于定位与入门，不能替代原始文献与元分析。
2. **分歧双方并举**：每条分歧都给出两方立场与「争议焦点」，不把一方写成结论。
3. **机制到教学需中介**：脑科学条目的应用建议均经认知与课堂研究转译，不做神经还原式推论。
4. **不构成诊断**：情境库不判断孩子「是不是」某种障碍，只给「何时该找专业帮助」的红线。
5. **来源分级标注**：1254 条证据中，423 条给出可直达的 DOI，590 条标到具体作品名，241 条只有作者与年份，没有无出处条目。匹配不到 DOI 的一律留空，不猜、不补造。
6. **覆盖不均衡**：以英语学界与中文可及文献为主，非西方传统与本土研究收录有限。
7. **关联是取舍结果**：779 条关联不代表全部关系，未收录不等于不存在。

## 质量自检

打开站内 `#/integrity` 可逐项核对：

- 分支计数之和是否等于领域条目数
- 是否缺详解、缺术语卡、缺证据、缺分歧
- 关联端点是否都指向真实条目
- 是否存在孤立节点
- 情境的关联条目、证据等级、活动指向是否有效
- 分诊项是否覆盖全部情境
- 证据分级（DOI / 作品名 / 作者与年份）与 DOI 覆盖率

## 贡献

新增条目时请保持：

- id 连续且唯一，加入 `roster-*` 与对应 `entries-*` / `dom-*`
- 必须填写 `definition`、`claims`、`agreements`、`disagreements`、`evidence`、`applications`、`terms`
- `startYear` 必须是数字（公元前用负数）
- 分歧必须写出双方立场与争议焦点，不得只写「有争议」
- 新关联必须两端 id 有效，并说明机制层面
- 提交前打开 `#/integrity` 确认仍为 0 错误
